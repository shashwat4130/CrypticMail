# MailRakhwala

**AI-Assisted Cryptographic Security Assessment for Email Communications**

> Problem Statement: SIH26159 — SecureMailScope

MailRakhwala is a passive, zero-decryption cryptographic security assessment framework for email infrastructure using SMTP, IMAP, and POP3 traffic captures.

It analyzes captured network traffic to assess TLS configuration, cryptographic parameters, certificate security, and related security risks.
